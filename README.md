# java-pattern-printing

A comprehensive collection of Java pattern printing programs for campus placements, covering pyramids, hollow shapes, and complex nested loop logic.

## 📌 Overview
This repository contains solutions to common console-based pattern problems asked in early-stage technical interviews by service-based companies. 

## 🗂️ Categories
* **Basic Grids:** Squares and rectangles using uniform rows/columns.
* **Triangles:** Right-aligned, left-aligned, and inverted triangles.
* **Pyramids:** Full centered pyramids and diamonds requiring space management.
* **Hollow Patterns:** Border-only shapes utilizing complex `if-else` boundary conditions.
* **Number/Character Patterns:** Floyd's triangle and alternating sequence patterns.

## 🧠 System Logic & Visualizations
Writing the code is only half the battle. To ensure a deep understanding of the loop mechanics, the logic for complex patterns is conceptualized visually before implementation. 

For advanced shapes (like the Butterfly or Hollow Diamond), refer to the logic documentation:
* **Flowcharts:** Outlining the step-by-step execution and variable state changes of the nested loops.
* **Level 0 / Level 1 DFDs:** Demonstrating how coordinate data flows through the mathematical conditions to generate the final console output.
